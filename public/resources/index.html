Download the CC0 icon set

Ready for your application

The download includes editable SVGs, PNG exports, light/dark variants, simplified 16–32 px artwork and Windows ICO/macOS ICNS document icons, plus monochrome and tintable filled UI icons. Embed a downloaded snapshot in your application.

Tintable SVGs use currentColor. Use them inline to inherit your interface color; choose fixed-color exports for external image elements. Preserve fill-rule="evenodd" when importing filled icons into a path renderer.
