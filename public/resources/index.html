Download the CC0 icon set

Ready for your application

The download includes dedicated 16, 20, 24, 32, 48 and 64 px SVG drawings, 1×/2× PNG exports, light/dark variants and Windows ICO/macOS ICNS document icons. Marks and filled UI icons also include monochrome and tintable versions. Embed a downloaded snapshot in your application.

Tintable SVGs use currentColor. Use them inline to inherit your interface color; choose fixed-color exports for external image elements. Preserve fill-rule="evenodd" when importing filled icons into a path renderer.

Avatars for circular crops

Use a padded avatar for profile images. Its background leaves room for a circular crop while keeping the complete mark intact. Upload the square PNG and let the host crop it; the files themselves remain square.

Designed at the size you use

A landscape picture and mirrored angle brackets combine image and code. Square and file treatments share the same brackets; a shallower picture fits below the file corner. The filled silhouette and substantial cutouts remain consistent at every size, with no extra detail added at larger sizes. Each row below uses the matching optical drawing at its actual displayed size, with a 2× export for high-density displays.

Choose by logical size first: a 16 px icon at 2× uses the 16 px drawing rendered at 32 physical pixels. It does not use the 32 px optical drawing. For intermediate sizes, scale up the next smaller drawing; above 64 px, use the 64 px master.
