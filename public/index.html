A small layer over SVG

Design once.
Make the inputs explicit.

Annotate the parts of an SVG that can change. An implementation discovers those inputs and their authored defaults, then applies replacement values to an independent SVG document.

Text, image references and paint values become addressable inputs. Multiple targets of the same kind can share one key. Optional metadata adds labels, descriptions and groups for editing tools. Geometry, fonts, clipping and layout stay with SVG.

Templates remain .svg files. Processing does not require fetching a schema or contacting this website.

The specification ↗

Portable contracts and canonical conformance references. Read the published 1.0.0 specification, or follow work in the repository.

.NET library and CLI ↗

Inspect templates and bind values in applications or command-line workflows. Get ScalableVectorTemplates and ScalableVectorTemplates.Cli on NuGet.

JavaScript library ↗

Inspect and bind templates in Node, browsers and Workers, with TypeScript declarations included. The official npm package name is @svt-project/svt-js; include the scope in dependencies and imports. The unscoped svt-js package is not this library.

Install the current release candidate with npm install @svt-project/svt-js@rc.
