SVT metadata vocabulary

The XML namespace for optional input presentation metadata in Scalable Vector Templates.

https://svt-project.github.io/ns/svt

This identifier distinguishes SVT metadata elements from SVG and RDF elements. The vocabulary describes input labels, descriptions, ordering and groups. Its definition belongs to the specification.

Namespace and format identity

A typical declaration is xmlns:svt="https://svt-project.github.io/ns/svt". The prefix svt is a convention; the namespace name is the identity. Use the exact identifier without a trailing slash.

The SVG root marker data-svt-version="1.0" selects the template format. It is separate from this metadata namespace and from implementation package versions. The data-svt-* binding attributes are unnamespaced.

Stable identity, offline processing

Specification editions evolve independently of this URI. A metadata vocabulary identity change requires an explicit namespace decision; a website redesign or specification revision does not silently change it.

This page is informative reference material, not a schema endpoint or parser dependency. Processors do not fetch it during inspection or binding. The specification and its canonical reference assets remain self-contained in their repository.

Following the URL may redirect to the HTML page at /ns/svt/. That HTTP behavior does not change the XML namespace name.
